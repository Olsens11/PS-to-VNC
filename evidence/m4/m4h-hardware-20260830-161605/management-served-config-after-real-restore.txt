# =============================================================================
# PS2VNC Configuration
# =============================================================================
#
# This file contains user-adjustable PS2VNC settings.
#
# It is intended to remain readable and editable by a person.  Future PS2VNC
# versions may add additional sections and settings here rather than creating
# separate configuration files for every feature.
#
#
# FILE FORMAT
# -----------
#
# Settings are grouped into sections:
#
#     [section]
#
# Individual settings use:
#
#     setting_name = value
#
# Blank lines are allowed.
#
# A line beginning with # is a comment.
#
# A # after a setting also begins a comment:
#
#     example = 123    # explanatory comment
#
#
# FORWARD COMPATIBILITY
# ---------------------
#
# Older PS2VNC versions ignore settings and sections they do not understand.
# This allows newer versions to add options without making the whole file
# unusable by older builds.
#
# Do not reuse the same recognized setting twice in one section.  Duplicate
# active settings are treated as an invalid configuration because it would be
# ambiguous which value should win.
#
#
# SAFETY
# ------
#
# Configuration values are treated only as DATA.
#
# PS2VNC does not execute shell commands, expand variables, evaluate
# expressions, or interpret executable text from this file.
#
# Numeric settings recognized by the PS2 client must contain plain decimal
# numbers.  Examples such as these are INVALID:
#
#     safe_width = $WIDTH
#     safe_width = 640+20
#     safe_width = 0x500
#     safe_width = 1280px
#     safe_width = $(command)
#
# If a recognized display setting is malformed or describes geometry that
# cannot safely fit inside the current video mode, PS2VNC will reject that
# stored display preset instead of using unsafe coordinates.
#
#
# =============================================================================
# DISPLAY
# =============================================================================
#
# These settings store the result of screen calibration.
#
# IMPORTANT:
#
# safe_width and safe_height are the dimensions of the ACTUAL USABLE remote
# desktop shown by PS2VNC.  They are NOT the larger temporary white calibration
# border that is drawn while adjusting the television.
#
# safe_x and safe_y move that calibrated area relative to the normal centered
# position:
#
#     negative safe_x = move left
#     positive safe_x = move right
#
#     negative safe_y = move up
#     positive safe_y = move down
#
# The valid numerical range depends on the physical video mode and the chosen
# safe width/height.  PS2VNC validates the complete rectangle before using it.
#
# The settings below are intentionally COMMENTED OUT in the template.
#
# Until calibration has actually been saved, PS2VNC should behave as though no
# stored display preset exists and show the normal calibration interface.
#
# When persistence is wired in, PS2VNC will update the active values while
# preserving the comments and unrelated future settings in this file.
#
