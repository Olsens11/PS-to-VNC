# M0D2 reproduction evidence

This directory preserves the evidence needed to explain the only
non-byte-identical intermediate observed during the byte-exact M0 B4A
reproduction.

The final generated ELF is not duplicated here because it is byte-identical to
the committed frozen B4A ELF under:

    baseline/frozen-b4a/PS2VNC.ELF

The two preserved gsHires objects demonstrate GCC slim-LTO intermediate
section-name variance.

They are evidence, not successor source authority.
