This directory owns the maintained successor-side tooling that reproduces the
Issue #7 live RFB provider-handoff experiment. The scripts temporarily prepare
and switch between canonical Xtigervnc and a Wayland/w0vncserver backend while
keeping the PS2-facing endpoint fixed at `192.168.50.1:5900`.

The entries below are also a human-readable guide to the code. They explain what
each maintained shell name represents, why it exists, and which part of setup,
handoff, observation, or teardown it controls. Preserving this apparatus does
not make it formal Issue #7 qualification evidence.
