# PS-to-VNC

PS-to-VNC is an independent homebrew remote-display and media project.

It is not affiliated with or endorsed by Sony Interactive Entertainment.

PS-to-VNC is the clean successor development project to the historical PS2VNC
research repository. The historical repository is preserved separately and is
not refactored by this project.

## Starting a new development conversation

The canonical handoff is intentionally short:

> Open `Olsens11/PS-to-VNC`. Read `AGENTS.md` and follow the fresh-session
> reconstruction procedure completely before doing any project work.

Do not infer current work from an old status paragraph, one open issue, or prior
conversation memory. The bootstrap procedure reconciles timestamped status
snapshots with the current GitHub issue/PR/branch/history record and relevant
live state before treating a `current` or `next` claim as present-day truth.

Canonical development entry point:

`AGENTS.md`

Canonical documentation router:

`docs/README.md`

Useful compatibility/reference entry points:

- `START_HERE.md` — migration-era compatibility redirect to `AGENTS.md`;
- `docs/INDEX.md` — mechanically complete compatibility index;
- `docs/PROJECT_IDENTITY.md` — project/repository identity;
- `docs/PROJECT_INTENT.md` — clean-reconstruction principle and values;
- `docs/status.md` — timestamped human status snapshot;
- `docs/development/BRANCH_WORKSTREAM_INDEX.md` — timestamped branch/workstream
  routing snapshot.
