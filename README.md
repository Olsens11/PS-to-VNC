# PS-to-VNC

PS-to-VNC is an independent homebrew remote-display and media project.

It is not affiliated with or endorsed by Sony Interactive Entertainment.

PS-to-VNC is the clean successor development project to the historical
PS2VNC research repository.

The historical repository is preserved separately and is not refactored by
this project.
