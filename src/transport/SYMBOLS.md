# Clean symbols — `src/transport`

DIRECTORY=src/transport
GENERATION=CLEAN_RECONSTRUCTION
COVERAGE=COMPLETE

This directory owns the shared PSTV framing vocabulary, including the exact provisional HELLO/ACCEPT/NOT_ACCEPTED representation; the PS2-side one physical PSTV stream and sole physical-I/O owner; framed sequence and serialized send; independent bounded logical RFB, AUDIO, and MPEG storage/credit authority; producer-driven media activity wakeups; exact MPEG START/RETIRE envelope relay with one session-local pending RETIRE-completion slot; explicit finite-producer MPEG completion publication; finite-session quiescence; and Transport-owned terminal convergence. The establishment codecs define bytes only—R8 does not wire PS2 Q4 connection establishment into the live runtime. Transport preserves Wire/session validity and payload identity but does not decide active MPEG generation meaning, producer lifecycle ordering, MPEG decoder resources, residual finalization, presentation, or application policy.
