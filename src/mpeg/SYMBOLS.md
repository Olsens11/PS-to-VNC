# Clean symbols — `src/mpeg`

DIRECTORY=src/mpeg
GENERATION=CLEAN_RECONSTRUCTION
COVERAGE=COMPLETE

This directory owns the clean MPEG decoder lifecycle, safe-stop core, one-picture borrowed decoded-frame publication boundary, and the concrete PS2 SMS-libmpeg/IPU decoder backend. It consumes only the public logical MPEG Transport seam, owns explicit caller-supplied feed/sequence/resource bounds, known-state IPU/DMAC prepare plus SMS initialize/picture/destroy ordering, TO_IPU feed DMA, decoder-call lifetime fencing, decoder-local picture ordinal/accounting, and truthful payload-versus-padded-transfer accounting. It does not own the physical PSTV receiver, exact-generation START/retirement orchestration, Pi producer/capture control, GS/presentation/compositor work, first-presentation clock arming, scheduling/drop policy, calibration, application orchestration, or hardware qualification.
